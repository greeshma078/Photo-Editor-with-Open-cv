# Photo-Editor-with-Open-cv
An AI-powered Photo Editor built with Streamlit and OpenCV that lets users upload, edit, and download images in real time. Features include brightness/contrast adjustment, grayscale, blur, warm filter, sharpen, portrait blur, plus creative effects like edge detection, sketch, and cartoon.
# 📸 AI-Powered Photo Editor using OpenCV & Streamlit

An interactive, end-to-end **Photo Editing Application** built with **Streamlit** and **OpenCV**, designed to let users upload, edit, and download images seamlessly.  
This project demonstrates practical computer vision techniques combined with a user-friendly web interface.

---

## 🚀 Project Highlights
- Real-time image upload and preview
- Brightness & contrast adjustment with sliders
- Multiple filters: grayscale, blur, warm tone, sharpen
- Portrait-style background blur
- Downloadable edited image
- Extra creative effects: edge detection, sketch, cartoon
- Streamlit-powered interactive UI

---

## 🧠 System Architecture
Image Upload  
→ Brightness & Contrast Adjustment  
→ Filter Selection (Grayscale, Blur, Warm, Sharpen, Portrait Blur)  
→ Extra Effects (Edge Detection, Sketch, Cartoon)  
→ Edited Image Preview  
→ Download Edited Image
