# 📸 AI-Powered Photo Editor using OpenCV & Streamlit

An AI-powered photo editing web application built with **Python**, **OpenCV**, and **Streamlit**. The application enables users to upload images, apply real-time image processing techniques, preview the results instantly, and download the edited images through an intuitive web interface.

This project demonstrates the practical application of **Computer Vision**, **Image Processing**, and **Interactive Web Development** using Python.

## 📖 Overview

The AI-Powered Photo Editor provides a lightweight, browser-based solution for performing common image editing operations without requiring professional desktop software. It integrates OpenCV's image processing capabilities with Streamlit's interactive interface to deliver a seamless user experience.

The project is designed as a portfolio-ready application that showcases practical computer vision concepts and rapid web application development.

---

## ✨ Key Features

- Upload images in **JPG, JPEG, or PNG** format
- Real-time image preview
- Brightness adjustment
- Contrast enhancement
- Grayscale conversion
- Gaussian blur
- Warm tone filter
- Image sharpening
- Portrait-style background blur
- Edge detection
- Pencil sketch effect
- Cartoon transformation
- Download edited images instantly
- Interactive and responsive Streamlit interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/greeshma078/photo-editor.git
```

### 2. Navigate to the Project Directory

```bash
cd photo-editor
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

Launch the Streamlit application using:

```bash
streamlit run app.py
```

The application will automatically open in your default web browser.
